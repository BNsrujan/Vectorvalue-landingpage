Renders a Lucide glyph at currentColor — the only sanctioned icon source in VectorValue.

Requires the Lucide UMD script on the host page:
<script src="https://unpkg.com/lucide@0.462.0/dist/umd/lucide.min.js"></script>

<Icon name="ruler" size={22} />

Stroke weight is 1.5 by default (technical line weight). Never inline hand-drawn SVG or emoji instead.
